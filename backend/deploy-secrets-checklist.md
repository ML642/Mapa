# Production deployment checklist

This project uses Vercel for the public frontend, Render for the backend and Redis, and MongoDB Atlas for the database.

## Render: `mapa-backend`

Set these values in the Render Environment page. Do not put any of them in the repository.

| Variable | Source |
| --- | --- |
| `MONGO_URI` | MongoDB Atlas connection string |
| `REDIS_URL` | Automatically injected by the `mapa-redis` Key Value service in `render.yaml` |
| `JWT_ACCESS_SECRET` | Automatically generated by Render Blueprint |
| `JWT_REFRESH_SECRET` | Automatically generated by Render Blueprint |
| `ALLOWED_ORIGINS` | Exact Vercel origin, for example `https://your-project.vercel.app` |
| `FRONTEND_URL` | The same public Vercel origin, without a trailing slash |
| `EMAIL_HOST` | SMTP provider host, for example `smtp-relay.brevo.com` |
| `EMAIL_PORT` | `2525` for Brevo on Render Free |
| `EMAIL_USER` | Provider SMTP login |
| `EMAIL_PASS` | Provider SMTP key |
| `EMAIL_FROM` | Verified sender email address |

Render Free blocks SMTP ports `25`, `465`, and `587`. Do not use Gmail SMTP from the free backend. With Brevo, verify the sender email and use the provider's SMTP login rather than the sender Gmail address.

## Vercel: public frontend

Set the following variables for Production and Preview deployments:

| Variable | Required | Description |
| --- | --- | --- |
| `VITE_API_URL` | Yes | Public Render backend URL, without a trailing slash |
| `VITE_MAPBOX_ACCESS_TOKEN` | Yes | Restricted public Mapbox token |
| `VITE_GOOGLE_CLIENT_ID` | Yes | Google OAuth Web client ID |
| `VITE_SITE_URL` | Recommended | Public Vercel URL |

The frontend has an SPA rewrite in `frontend/vercel.json`, so direct visits to `/register`, `/login`, and other client routes resolve to the React application.

## MongoDB Atlas

- Create a database user with the least permissions needed by the backend.
- Add Render network access according to the Atlas connection policy in use.
- Keep the Atlas URI only in Render as `MONGO_URI`.

## Final smoke test

1. Open `GET /health` on the Render backend.
2. Open the Vercel frontend and confirm events load on the map.
3. Register a new account and verify the email code arrives.
4. Confirm login, password reset, and Google sign-in work.
5. Check that direct navigation to `/register` does not return a Vercel 404 page.
